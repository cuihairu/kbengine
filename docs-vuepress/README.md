## 欢迎使用 KBEngine

KBEngine 是一套开源的 MMO 服务端引擎，让开发者专注于游戏逻辑开发，而无需关心底层网络通信、数据库存储等技术细节。

### 核心特性

- **Python 脚本**：使用 Python 编写游戏逻辑，开发效率高
- **分布式架构**：支持多服务器部署，轻松扩展
- **数据库抽象**：支持 MySQL、Redis 等多种数据库
- **Web 控制台**：提供可视化的管理界面
- **完整文档**：提供详细的 API 文档和教程
