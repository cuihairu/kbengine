## Welcome to KBEngine

KBEngine is an open source MMO server engine that allows developers to focus on game logic development without worrying about underlying technical details such as network communication and database storage.

### Core Features

- **Python Scripting**: Write game logic in Python for high development efficiency
- **Distributed Architecture**: Support multi-server deployment, easy to scale
- **Database Abstraction**: Support multiple databases like MySQL, Redis
- **Web Console**: Provide visual management interface
- **Complete Documentation**: Detailed API documentation and tutorials
